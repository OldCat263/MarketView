# MarketView

② About 区域（2-3 行）
🇬🇧 English:
One-stop real-time global market data display platform. 8 modules covering China A-shares, Hong Kong stocks, US stocks, ETFs, indices, cryptocurrencies, K-line charts (ECharts 5 triple-panel with MA/BOLL/MACD), and financial news. SSE real-time push with sub-second latency. Pure vanilla JS frontend, FastAPI backend, zero disk storage, responsive mobile/tablet/desktop.
🇨🇧 中文：
一站式全球金融市场实时数据展示平台。8 个模块覆盖 A股、港股、美股、ETF、指数、加密货币、K线图（ECharts 5 三联图 + MA/BOLL/MACD 指标）和财经新闻。SSE 实时推送秒级更新，纯原生前端 + FastAPI 后端，零磁盘存储，手机/平板/桌面三端自适应。
