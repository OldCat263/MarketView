## #A: 前端懒惰加载

**根因**：`preloadAll()` 加载全部模块后才让用户交互，美股卡住全部。

**改法**：首页立即展示 8 张卡片，不等到全部加载完。用户点击哪个才加载哪个。

**文件**：[frontend/js/core.js](frontend/js/core.js)

```javascript
// preloadAll() 中，Promise.all 改为：先展示卡片，后逐个加载

async function preloadAll() {
    // ... (现有初始化代码) ...

    // V1.8.6: 改为逐个后台加载，首页立即可用
    var mods = MODULES.filter(function(m) {
        return m.id !== 'crypto' && !m.placeholder;
    });

    // 先标记全部卡片为"加载中"
    mods.forEach(function(m) {
        var card = document.getElementById('card_' + m.id);
        if (card) {
            card.querySelector('.card-status .status').textContent = '⏳';
            card.querySelector('.card-count').textContent = '加载中';
        }
    });

    // 逐个加载（不阻塞首页交互）
    for (var i = 0; i < mods.length; i++) {
        var m = mods[i];
        try {
            var cached = cacheGet(m.id, true);
            if (cached) {
                ST[m.id] = { rows: cached.rows, cols: cached.cols, page: 1, sortKey: null, sortDir: 1, updateTime: cached.time, search: '', fetchTime: Date.now() };
                LOADED[m.id] = true;
                var card = document.getElementById('card_' + m.id);
                card.querySelector('.card-status .status').textContent = '✅';
                card.querySelector('.card-count').textContent = cached.rows.length + ' 条';
            } else {
                await loadModule(m.id);
            }
            loadedCount++;
            latestUpdate = Date.now();
            var pct = Math.round(loadedCount / mods.length * 100);
            document.getElementById('loadBar').style.width = pct + '%';
        } catch (e) {
            loadedCount++;  // 即使失败也计数
            var card2 = document.getElementById('card_' + m.id);
            card2.querySelector('.card-status .status').textContent = '❌';
        }
    }
    // ... (完成提示) ...
}
```

**验收**：打开首页立即看到 8 张卡片（⏳ 状态），无需等美股加载完。

## #B: K线服务端缓存

**根因**：每次切股票 / 切周期都重新请求腾讯 API，200-2000ms。

**改法**：`main.py` 加 `_kline_cache`，`{module}_{code}_{period}` → `{data, ts}`，TTL 5min。

**文件**：`backend/main.py`

```python
# main.py 顶部加
_kline_cache = {}
_kline_lock = threading.Lock()

# kline_endpoint 改为：
@app.get('/api/kline/{module}/{code}')
def kline_endpoint(module: str, code: str, period: str = '1d', count: int = 750):
    cache_key = f'{module}_{code}_{period}_{count}'
    # 读缓存（5min TTL）
    with _kline_lock:
        cached = _kline_cache.get(cache_key)
        if cached and time.time() - cached['ts'] < 300:
            return JSONResponse(cached['data'])
    # 未命中 → 正常计算
    fn = KL_FN.get(module)
    if not fn:
        return JSONResponse({'error': f'unknown module: {module}'}, status_code=404)
    try:
        rows = fn(code, period, count)
        if not rows:
            return JSONResponse({'data': [], 'ma': {}, 'boll': {}, 'macd': {}, 'ts': time.time()})
        closes = [r[2] for r in rows]
        ma = indicators.calc_ma(closes)
        boll = indicators.calc_boll(closes)
        macd = indicators.calc_macd(closes)
        name = ''
        for key, (def_code, def_name) in KL_NAMES.items():
            if key == module:
                name = def_name
                break
        resp_data = {
            'code': code, 'name': name, 'module': module, 'period': period,
            'data': rows, 'ma': ma, 'boll': boll, 'macd': macd, 'ts': time.time(),
        }
        # 写缓存
        with _kline_lock:
            _kline_cache[cache_key] = {'data': resp_data, 'ts': time.time()}
        return JSONResponse(resp_data)
    except Exception as e:
        return JSONResponse({'error': str(e)}, status_code=500)
```

**验收**：第一次请求 ~1s，第二次请求同股票同周期 ~5ms（缓存命中）。

## #C: 美股热股预拉

**根因**：美股全量 8000+ 只全部拉取后才可用，但用户实际只看前几十只热门股。

**改法**：`us.py` 的 `_from_tencent_threaded` 改为先拉成交量 top 50，其余后台补。

**文件**：`backend/fetcher/us.py`

> **重要前置**：#1 的美股磁盘缓存写入时，**代码列表需按成交量降序排序**。AkShare 返回顺序不保证按成交量，需显式排序后再缓存，确保 `codes[:100]` 取到的是真正的热股。

```python
# _load_us_codes() 中，缓存前加排序：
# 在 ak.stock_us_spot_em() 返回 df 后：
codes_with_vol = [(str(r['代码']), float(r.get('成交量', 0) or 0)) for _, r in df.iterrows()]
codes_with_vol.sort(key=lambda x: x[1], reverse=True)  # 成交量降序
codes = [c for c, _ in codes_with_vol]

# fetch_shard 改为：
def fetch_shard(shard_idx, total_shards):
    codes = _load_us_codes()
    # V1.8.6: 分片 0 先拉热门股（确保首页秒开）
    if shard_idx == 0:
        # 拉前 100 只代码（按代码列表顺序即可，通常按成交量排序）
        hot = codes[:100]
        return _from_tencent_threaded(hot, workers=3)
    # 其余分片正常拉
    chunk = max(1, len(codes) // total_shards)
    my = codes[shard_idx*chunk:(shard_idx+1)*chunk] if shard_idx < total_shards-1 else codes[shard_idx*chunk:]
    return _from_tencent_threaded(my, workers=min(3, len(my)//50+1))
```

**验收**：美股卡片在第一个滚动周期后（~3s）即显示数据（前 100 只）。

## #D: index.html 首屏快照

**根因**：前端等着后端 SSE 推送第一帧数据，0 数据时首页 8 张卡片全显示"加载中"。

**改法**：后端在 `_initial_load` 并行完成后，把 6 模块首页数据合并写入一个 JSON 快照。前端 `<script>` 内嵌这个快照（内联 JSON），无需任何 HTTP 请求即渲染首页。

**文件 1**：`backend/main.py` — **必须放在 `ThreadPoolExecutor.wait()` 之后（6 模块全加载完才写快照）**：

```python
# _initial_load() 函数内，concurrent.futures.wait(futures) 之后：
def _write_snapshot():
    import os
    snapshot = {}
    for key in SHARD_CFG:
        data = _cached_get(key)
        if data != '[]' and data != '{}':
            snapshot[key] = json.loads(data)
    snapshot['ts'] = time.time()
    snapshot_path = os.path.join(os.path.dirname(os.path.abspath(__file__)), '..', 'frontend', 'snapshot.json')
    with open(snapshot_path, 'w', encoding='utf-8') as f:
        json.dump(snapshot, f, ensure_ascii=False)
    print('[snapshot] updated')

# 在 ThreadPoolExecutor.wait(futures) 之后调用：
_write_snapshot()
# 注意：必须在 wait() 之后调用！_initial_load 是 fire-and-forget 线程，
# 只有 wait() 之后才确保 6 模块全加载完，此时缓存才是完整数据。
```

**同时**：`.gitignore` 加一行：

```
frontend/snapshot.json
```

**文件 2**：`frontend/index.html` — 在 `<script src="js/core.js"></script>` 之前加：

```html
<script>
// V1.8.6: 首屏快照 — 零 HTTP 渲染
window._SNAPSHOT = null;
fetch('snapshot.json?' + Date.now())
  .then(function(r) { return r.json(); })
  .then(function(d) {
    window._SNAPSHOT = d;
    // 如果 core.js 还没加载，core.js 启动后会读 _SNAPSHOT
  })
  .catch(function() {});
</script>
```

**文件 3**：`frontend/js/core.js` — `preloadAll()` 开头优先读快照：

```javascript
// preloadAll() 最前面加：
// V1.8.6: 首屏快照优先 — 零等待渲染
if (window._SNAPSHOT && !firstVisit) {
    Object.keys(window._SNAPSHOT).forEach(function(key) {
        if (key === 'ts') return;

        if (Array.isArray(d)) {
            var cols = d.length > 0 ? Object.keys(d[0]) : [];
            ST[key] = { rows: d, cols: cols, page: 1, sortKey: null, sortDir: 1, updateTime: '', search: '', fetchTime: Date.now() };
            LOADED[key] = true;
            var card = document.getElementById('card_' + key);
            if (card) {
                card.querySelector('.card-status .status').textContent = '✅';
                card.querySelector('.card-count').textContent = d.length + ' 条';
            }
            loadedCount++;
        }
    });
    latestUpdate = Date.now();
}
```

**验收**：打开页面后无需等后端，立即看到上次的数据（快照），SSE 连上后自动切到实时。

## #E: 模块就绪信号

**根因**：用户不知道哪个模块加载完了，哪個还在等。

**改法**：`/api/health` 返回各模块就绪状态，前端根据状态显示卡片颜色。

**文件 1**：`backend/main.py`

```python
@app.get('/api/health')
def health():
    status = {'status': 'ok'}
    for key in SHARD_CFG:
        data = _cached_get(key)
        status[key] = (data != '[]' and data != '{}')
    return status
```

**文件 2**：`frontend/js/core.js` — `refreshStamp()` 中或独立 `setInterval` 中：

```javascript
// 每 5s 轮询 health
setInterval(function() {
    fetch(MV.API + '/api/health')
        .then(function(r) { return r.json(); })
        .then(function(s) {
            MODULES.forEach(function(m) {
                var card = document.getElementById('card_' + m.id);
                if (!card) return;
                var dot = card.querySelector('.card-status .status');
                if (s[m.id]) {
                    if (dot && dot.textContent === '⏳') dot.textContent = '✅';
                    card.style.opacity = '1';
                } else {
                    card.style.opacity = '0.5';  // 未就绪的卡片半透明
                }
            });
        })
        .catch(function() {});
}, 5000);
```

**验收**：首页卡片从半透明逐渐变亮——已就绪的立即明亮，未就绪的半透明等待。用户一眼知道能点哪个。
