## #1 `kline.py:91` — 分钟K线取最旧数据

**文件**：[backend/fetcher/kline.py](../backend/fetcher/kline.py)

**问题**：`raw[:count]` 取数组前 count 条（最旧数据），日K 用 `raw[-count:]`（最新数据）

**改法**：

```diff
-        raw = raw[:count]
```

## #3 `utils.py:10` — fillna(0) 破坏时间列

**文件**：[backend/fetcher/utils.py](../backend/fetcher/utils.py)

**问题**：`fillna(0)` 作用于全量 DataFrame，NaT 被填为 0/epoch，再 `astype(str)` 输出错误值

**改法**：先转时间列为 str，再对非时间列 fillna(0)：

```diff
 def _to_records(df) -> list:
     if df is None or len(df) == 0: return []
-    df = df.fillna(0)
     for col in df.columns:
         d = str(df[col].dtype)
         if any(k in d for k in ('datetime', 'timestamp', 'period', 'timedelta')):
             df[col] = df[col].astype(str)
+        else:
+            df[col] = df[col].fillna(0)
     return df.to_dict('records')
```

## #4 `__init__.py` — 逐模块 import 防全站崩

**文件**：[backend/fetcher/__init__.py](../backend/fetcher/__init__.py)

**问题**：`from . import crypto, stock, etf, hk, us, index_mod, news` 一行炸全炸

**改法**：逐模块 `importlib.import_module` + try/except，失败时提供空 fallback：

```python
"""MarketView 数据获取层 — 每模块独立文件"""

def _safe_import(mod_name):
    """逐模块导入，单模块失败不影响其他"""
    import importlib
    try:
        return importlib.import_module('.' + mod_name, __package__)
    except Exception as e:
        print(f'[fetcher] WARN: {mod_name} import failed: {e}')
        return None

# ── 加密货币 ──
_crypto = _safe_import('crypto')
crypto_status = _crypto.status if _crypto else (lambda: {'available': False, 'message': '模块加载失败'})
get_crypto_json = _crypto.get_json if _crypto else (lambda: '[]')
fetch_crypto_shard = _crypto.fetch_shard if _crypto else (lambda i,n: [])

# ── A股 ──
_stock = _safe_import('stock')
get_stock_json = _stock.get_json if _stock else (lambda: '[]')
fetch_stock_shard = _stock.fetch_shard if _stock else (lambda i,n: [])

# ── ETF ──
_etf = _safe_import('etf')
get_etf_json = _etf.get_json if _etf else (lambda: '[]')
fetch_etf_shard = _etf.fetch_shard if _etf else (lambda i,n: [])

# ── 港股 ──
_hk = _safe_import('hk')
get_hk_json = _hk.get_json if _hk else (lambda: '[]')
fetch_hk_shard = _hk.fetch_shard if _hk else (lambda i,n: [])

# ── 美股 ──
_us = _safe_import('us')
get_us_json = _us.get_json if _us else (lambda: '[]')
fetch_us_shard = _us.fetch_shard if _us else (lambda i,n: [])

# ── 指数 ──
_index = _safe_import('index_mod')
get_index_json = _index.get_json if _index else (lambda: '[]')
fetch_index_shard = _index.fetch_shard if _index else (lambda i,n: [])

# ── 新闻（V1.8.0）──
_news = _safe_import('news')
get_news_json = _news.get_news_json if _news else (lambda: '[]')
fetch_news_shard = _news.fetch_news_shard if _news else (lambda i,n: [])
```

## #5 `core.js:23` — formatChinese 涨跌额误加 %

**文件**：[frontend/js/core.js](../frontend/js/core.js)

**问题**：`col.includes('涨跌')` 同时命中 '涨跌幅' 和 '涨跌额'，涨跌额 `0.50` 显示为 `0.50%`

**改法**：删掉 `|| col.includes('涨跌')`（'涨跌幅' 已由前一个 `col.includes('涨跌幅')` 覆盖）：

```diff
-    if (col.includes('涨跌幅') || col.includes('涨跌') || col.includes('振幅') || col.includes('换手率'))
+    if (col.includes('涨跌幅') || col.includes('振幅') || col.includes('换手率'))
       return v.toFixed(2) + '%';
```

**验收**：浏览器打开 A股/ETF/港股/美股/指数模块，涨跌额列显示数字（`+0.50`）而非百分比（`0.50%`）
