# MarketView V1.6.0 实时化实施清单

> **写给执行者**：按 L1→L2→L3 顺序，每任务独立可测。项目无测试框架，验收用运行命令。守 CLAUDE.md 铁律（核心文件不变、零本地存储、免费公开API、模块独立封装）。

**目标：** 全模块实时刷新（SSE 推送 + 滚动分片），单元格 diff 闪动，时间显示全实时，全量零截断。

**架构：** 后端每模块独立滚动 daemon 线程刷新分片内存缓存 → SSE 推送分片变更 → 前端 EventSource 订阅当前模块 → diff 旧数据 → 变化单元格 flash 闪动。worker=1。

**技术栈：** FastAPI + httpx(并发) + akshare + 腾讯 qt.gtimg.cn + SSE(text/event-stream) + 原生 JS EventSource

```python
import httpx, asyncio

async def _fetch_all_concurrent(codes, batch=50, concurrency=11):
    """codes: 全量代码列表；分批并发拉取腾讯行情"""
    batches = [codes[i:i+batch] for i in range(0, len(codes), batch)]
    sem = asyncio.Semaphore(concurrency)
    async with httpx.AsyncClient(timeout=10) as client:
        async def one(b):

                return parse_tencent(r.text)  # 复用现有解析
        results = await asyncio.gather(*[one(b) for b in batches])
    return [x for sub in results for x in sub]
```

### Task 2.2：每模块滚动 daemon 线程

**Files:** `backend/main.py`, `backend/fetcher/*.py`

- [ ] **Step 1：每模块加 fetch_shard 函数**

- [ ] **Step 2：main.py 加滚动线程**

```python
import threading, asyncio

def _roller(key, fetch_shard_fn):
    cfg = SHARD_CFG[key]
    i = 0
    while True:
        try:
            data = asyncio.run(fetch_shard_fn(i, cfg['n']))
            with _cache_lock:
                _cache.setdefault(key, {'shards': {}, 'cols': []})
                _cache[key]['shards'][i] = {'data': data, 'ts': time.time()}
        except Exception as e:
            print(f'[roller] {key} shard {i} fail: {e}')
        i = (i + 1) % cfg['n']
        time.sleep(cfg['interval'])
```

- [ ] **Step 3：lifespan 启动 6 个滚动线程**

```python
@asynccontextmanager
async def lifespan(app):
    for key, fn in [('stock', fetch_stock_shard), ('etf', fetch_etf_shard),
                    ('hk', fetch_hk_shard), ('us', fetch_us_shard),
                    ('index', fetch_index_shard), ('crypto', fetch_crypto_shard)]:
        threading.Thread(target=_roller, args=(key, fn), daemon=True).start()
    yield
```

```python
from fastapi.responses import StreamingResponse
import json as _json

@app.get("/api/stream/{module}")
async def stream_module(module: str):
    if module not in _sse_queues:
        return StreamingResponse(iter(['event: error\ndata: unknown\n\n']), media_type='text/event-stream')
    q = _sse_queues[module]
    async def gen():
        while True:
            try:
                msg = q.get(timeout=30)
                yield f'data: {_json.dumps(msg)}\n\n'
            except Exception:
                yield ': ping\n\n'
    return StreamingResponse(gen(), media_type='text/event-stream')
```

```javascript
function applyShardUpdate(module, msg) {
  const st = ST[module];
  if (!st) return;
  const byCode = {};
  msg.data.forEach(r => byCode[r['代码']] = r);
  st.rows.forEach((old, idx) => {
    const neu = byCode[old['代码']];
    if (!neu) return;
    Object.keys(neu).forEach(k => {
      if (old[k] != neu[k]) {
        old[k] = neu[k];
        flashCell(module, idx, k, neu[k] > old[k]);
      }
    });
  });
  // 更新时间
  ST[module].ts = msg.ts;
  updateTime(module);
}
```
