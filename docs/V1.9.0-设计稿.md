## 三、量化因子设计（方案 B）

### 3.1 十个因子（全用已有 `indicators.py` + K线数据计算，零新增依赖）

**基础因子（Q1-Q5）**：

| # | 因子 | 计算方式 | 数据源 |
|---|------|---------|--------|
| Q1 | 动量 | 20 日收盘价收益率 | K线 close |
| Q2 | 反转 | 5 日收益率取负（短期反转效应） | K线 close |
| Q3 | 波动率收缩 | BOLL 带宽当前值 / 20 日均值，收缩→突破概率↑ | `indicators.py:calc_boll` |
| Q4 | 放量 | 今日成交量 / 20 日均量 | K线 volume |
| Q5 | 均线排列 | MA5 > MA10 > MA20 > MA60 给正分 | `indicators.py:calc_ma` |

**新增因子（Q6-Q10）**：

| # | 因子 | 计算方式 | 预测逻辑 | 数据源 |
|---|------|---------|---------|--------|
| Q6 | RSI(14) | `100 - 100/(1 + avg_gain_14d / avg_loss_14d)` | <30 超卖→买, >70 超买→卖 | K线 close |
| Q7 | ATR(14) | 14日真实波幅均值 = `avg(max(h-l, |h-pc|, |l-pc|))` | 当前波动率 vs 历史中枢，判断环境 | K线 h/l/close |
| Q8 | VPT量价趋势 | 累积 `(close - prev_close) / prev_close * volume` | 量价同向→趋势健康，背离→警示 | K线 close/vol |
| Q9 | 50日位置 | `(close - 50d_low) / (50d_high - 50d_low)` | 临近新高→强势，临近新低→弱势 | K线 h/l/close |
| Q10 | 北向关联 | 当前日北向资金净流入 vs 20日均值 | 聪明钱跟随（仅A股/港股，其余模块默认50分） | `fundamentals.py` |

新增 5 个因子均为纯 Python 计算（Q6/Q7/Q8/Q9 用 K线数据，Q10 已有 fundamentals 缓存）。`indicators.py` 追加 3 个函数（`calc_rsi`/`calc_atr`/`calc_vpt`），~50 行。

### 3.2 因子评分规则（连续映射）

每个因子映射到 0-100，clamp 到 [0, 100]：

**基础因子（Q1-Q5）**：
- 动量：`clamp(动量% / 10% * 100, 0, 100)` — +5% → 50分, +10% → 100分
- 反转：`clamp(反转% / 5% * 100, 0, 100)` — +3% → 60分, +5% → 100分
- 波动率收缩：`clamp(收缩% / 30% * 100, 0, 100)` — 15% → 50分, 30% → 100分
- 放量：`clamp((量比-1) / 1.0 * 100, 0, 100)` — 1.5倍 → 50分, 2.0倍 → 100分
- 均线排列：MA5>MA10>MA20>MA60 → 100分, 部分交叉 → 逐条检查每条+25分

**新增因子（Q6-Q10）**：
- RSI：`rsi < 30 → clamp((30-rsi)/30 * 100, 0, 100)`, `rsi > 70 → clamp((rsi-70)/30 * 100, 0, 100)`, 30-70 → 0分（中性区不给分）
- ATR：`clamp((atr - atr_20d_min) / (atr_20d_max - atr_20d_min) * 100, 0, 100)` — 波动率在历史范围中的位置
- VPT：`clamp((vpt - vpt_20d_min) / (vpt_20d_max - vpt_20d_min) * 100, 0, 100)` — 量价趋势在近期范围的位置
- 50日位置：`clamp(位置% * 100, 0, 100)` — 0%(=新低)→0分, 100%(=新高)→100分
- 北向关联：`clamp((北向净流入/20日均值 - 1) * 100, 0, 100)` — 翻倍流入→100分, 流出→0分；非A股模块默认50分

10 因子等权平均 → `quant_score`（0-100）。因子越多，单一噪音被稀释越干净。

### 3.3 历史相似场景匹配

`_find_similar_setups(chanlun_result, kline_rows, N=3)`：

1. 取当前最新中枢的 ZG/ZD/级别
2. 遍历历史上所有同级别中枢（750 根 K线中的）
3. 按 ZG/ZD 绝对偏差排序，选最接近的 N 个
4. 返回每个的日期、中枢参数、30 日后涨跌幅

输出格式：
```json
[
  {"date": "2025-03-15", "zg": 1680, "zd": 1620, "result_30d": "+12.3%", "signal": "一类买"},
  {"date": "2024-09-02", "zg": 1550, "zd": 1500, "result_30d": "+8.1%", "signal": "二类买"},
  {"date": "2024-01-18", "zg": 1720, "zd": 1660, "result_30d": "-5.2%", "signal": "假突破"}
]
```

此结果注入 AI prompt（见下）。

### 3.4 多周期确认

日线买卖点信号用周线趋势做置信度调节（`scorer.py` 内 ~20 行）：

```
日线信号  + 周线走势     → 置信度调整
一类买    + 上涨/盘整    → ×1.3（大小周期共振）
一类买    + 下跌         → ×0.7（逆大势打七折）
二类买    + 上涨         → ×1.2
三类买    + 上涨         → ×1.1
卖点      + 下跌         → ×1.3
```

调用方式：`scorer.py` 的 `score_single()` 内部对同一标的按 module 分派到对应 fetch 函数：

```python
# scorer.py 内部
from fetcher.kline import fetch_kline_stock, fetch_kline_etf, fetch_kline_hk, \
    fetch_kline_us, fetch_kline_index, fetch_kline_crypto

_KL_FN = {'stock':fetch_kline_stock, 'etf':fetch_kline_etf, 'hk':fetch_kline_hk,
          'us':fetch_kline_us, 'index':fetch_kline_index, 'crypto':fetch_kline_crypto}

fn = _KL_FN.get(module)
if fn:
    weekly_rows = fn(code, '1w', 200)
    weekly_cl = chanlun.analyze(weekly_rows, ...)
```

不算新的 API 端点，纯内部逻辑。

### 3.5 百分位排名校准

`rank_batch()` 返回每只票的绝对分数 + **相对排名**：

```json
{
  "code": "sh600519",
  "total_score": 78,
  "pct_total": 12,       // 总分前12%
  "pct_chanlun": 8,       // 缠论分前8%
  "pct_quant": 15,        // 量化分前15%
  "pct_fundamental": 22   // 基本面分前22%
}
```

让用户知道"这只票在 300 只候选里排第几"，比裸分 78 更有决策价值。

## 十三、精度要诚实

> **核心定位**：本系统是**多因子筛选+分析工具**，不预测价格方向。它回答"哪些标的符合多维度买入条件、历史上类似信号表现如何"，不回答"明天涨还是跌"。所有历史统计不代表未来收益。

| 输出 | 给什么 | 不给什么 |
|------|--------|---------|
| 回测统计 | "该信号类型近2年胜率62.3%（47笔），夏普1.2，最大回撤8%，盈利因子1.8" | "这只票明天涨" |
| 历史对比 | "历史上 3 次相似中枢结构中 2 次上涨，平均 +8.2%" | "当前大概率涨" |
| 百分位排名 | "总分78/100（全市场前12%），缠论分85（前8%）" | "78分"（裸数字不可比较） |
| 多周期确认 | "日线一类买 + 周线上涨 → 共振系数1.3" | 单周期信号忽略大势 |
| AI 置信度 | "置信度 78/100" 附带分析依据 | 不解释为什么的裸数字 |
| 量化因子 | 10因子逐项得分 + 趋势解读 | 单一总分的黑箱 |
| 免责声明 | 前端 AI 报告底部固定："历史数据不代表未来收益，仅供参考" | — |
