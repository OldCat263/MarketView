## 一、A股实时行情模块 (stock)

### 数据源 1：新浪财经 API

| 项目 | 内容 |
|------|------|
| **URL** | `http://hq.sinajs.cn/list=sh600519,sz000001,sh601318` |
| **适用模块** | stock |
| **请求方式** | GET，支持批量（逗号分隔多个代码） |
| **是否需要特殊 Header** | ⚠️ 需要 `Referer: https://finance.sina.com.cn`，否则可能返回 403 |
| **验证结果** | ✅可用 |
| **请求延迟** | ~80-230ms |

**返回字段（逗号分隔的字符串）：**
```
var hq_str_sh600519="XD贵州茅,1199.000,1184.080,1168.630,1199.000,1168.100,1168.630,1168.780,5006647,5922014054.000,..."
```
- 字段顺序：名称、今开、昨收、最新价、最高、最低、买一价、卖一价、成交量、成交额、日期、时间
- 还包含五档买卖盘数据

**优点：** 支持批量请求，延迟低，字段丰富（含五档盘口）
**缺点：** 需要 Referer header，非官方接口可能被封 IP

## 四、综合对比总结

| 数据源 | 模块 | 格式 | 需要 Header | 批量 | 延迟 | 列表支持 | 推荐度 |
|--------|------|------|-------------|------|------|----------|--------|
| 新浪 hq.sinajs.cn | stock/etf/index | 文本 | ⚠️ Referer | ✅ | ~80-230ms | ❌ | ⭐⭐⭐⭐ |
| 腾讯 qt.gtimg.cn | stock/etf/index | 文本 | ❌ | ✅ | ~160-270ms | ❌ | ⭐⭐⭐⭐⭐ |
| 东方财富 push2 | stock/etf/index | JSON | ❌ | ✅(列表) | ~120-230ms | ✅ | ⭐⭐⭐⭐⭐ |
| 东方财富 push2his | stock/etf/index | JSON | ❌ | ❌ | ~120ms | ❌ | ⭐⭐⭐⭐ |

### 推荐方案

1. **主数据源：东方财富 push2**
   - 优势：JSON 格式、支持全市场列表、单只查询、字段可定制、无需 Header
   - 三个模块通用，接口统一

2. **备用数据源：腾讯 qt.gtimg.cn**
   - 优势：无需 Header、字段最丰富、延迟稳定
   - 适合做数据校验和兜底

3. **低延迟场景：新浪 hq.sinajs.cn**
   - 优势：延迟最低（~80ms）、支持批量
   - 注意：需要 Referer header

4. **K线历史数据：东方财富 push2his**
   - 优势：支持多周期（日/周/月/分钟），JSON 格式
   - 三个模块通用

## 五、API 参数速查

### 东方财富 secid 前缀规则
- `1.` → 上交所（SH）股票/ETF/指数，如 `1.600519`(贵州茅台), `1.510300`(沪深300ETF), `1.000001`(上证指数)
- `0.` → 深交所（SZ）股票/ETF/指数，如 `0.000001`(平安银行), `0.399001`(深证成指)
