# 缠中说禅炒股文章汇总

> 缠中说禅（李彪，1970-2008），中国著名操盘手、缠论创始人。
> 2006年6月7日在新浪开博，ID为"缠中说禅"，共留下 1134 篇精彩文章。
> 其中"教你炒股票"系列 108 课是其股市理论核心，被统称为"缠论"。

---

## 一、人物简介

缠中说禅，本名**李彪**，1970 年左右出生于广州。

- 1988 年广州广雅中学高中毕业
- 1988-1992 年就读于广州中山大学数学系
- 1998 年起成功操盘亿安科技，造就了中国首只百元股
- 2005 年 6 月起重新进入股市
- 2006 年 6 月 7 日在新浪开博，自命"全球第一博客"
- 2007 年创立青岛木子创业投资中心
- 2008 年 10 月 19 日因鼻咽癌去世，年仅 38 岁

**主要成就：**
- 准确预言了 2007 年股市大顶（6124.04 点）
- 2005 年神奇预测股市见底，马上会有波澜壮阔的大牛市
- 2007 年下半年预言美国次贷危机将引发全球金融危机
- 创造了完整的"缠论"技术分析体系

## 三、心法荟萃（核心语录整理）

### 心态篇

1. 一定不要追高买股票，一定要有这样的心态，它爱涨多少是多少，权当这股票不存在。

2. 股票只有两种，买点上的股票都是好股票，否则就是垃圾股票；大级别买点的就是最好的绩优股，耐心等待股票成为真正的绩优股，这才是真正的心态。

3. 心态要稳，对股票、点位都不要有感情，只看市场的信号。应该对买卖点有感情。

4. 失误的原因永远与市场无关，找原因，只能找自己的原因，任何一次失误都要马上总结。

5. 为什么不能把自己变成狼，这和资金大小无关。只要你能买点买、卖点卖，就是最凶猛的狼。

6. 操作，一定要冷静，有钱，什么都有，还怕没有好股票？

### 市场与节奏篇

1. 市场里，任何的侥幸都只能是暂时的，而且会被市场所加倍索还。

2. 急着挣钱的心理是市场参与者的大忌，连自己的心都控制不住，对自己的贪婪、欲望都不能控制，是不能在市场中长久成功的。

3. 市场只会给耐心者以回报；股票是需要养大的，天天要新股票的，肯定永远是小资金，小打小闹。

4. 本ID只知道跟着市场的节奏舞蹈，只要跟着市场的节奏，在刀锋上一样可以凌波微步。

5. 在市场中，只能存天理，灭人欲。买卖点是合力的结果，买点出来，涨就是天经地义。

6. 市场不是慈善机构。该涨的时候要凶，该跌的时候一样要凶，关键是你的技术。

### 买卖点篇

1. 所有情况都逃不过高位背驰卖，低位背驰买，不预测。

2. 操作，归根结底就是买点买、卖点卖。

3. 买了股票，就一定要从买点一直持有到至少是同级别的第一卖点。

4. 第三类买点一定要等到次级别的背驰或双次回拉确认。

5. 所有买点都肯定是调整时出现的。

6. 精通本ID的理论后，涨跌的分别就会消失，在你脑子里，只有买点卖点，没什么涨跌。

### 交易习惯篇

1. 不追高是投资第一要点。永远不追涨杀跌。

2. 一定要强迫自己把股票的种类降下来，对于小资金来说，一定要集中点，一般来说，100万以下的资金，超过5只都太多了。

3. 有买点吗？有符合自己操作的级别的买点吗？这才是你受用一生的思维模式。

4. 一定要习惯于在放量突破回调时买股票，这样风险小很多。

5. 一定要在调整结束后将启动时介入，这是在市场中生存的最好办法。

### 震荡与降低成本篇

1. 震荡是好事，震荡正是短差最好的机会，对于节奏好的人，越震荡成本越低，最好天天震。

2. 盘整就要敢抛敢买，一旦出现第三类卖点进入破位急跌，就要等跌透。

3. 一个周线中枢的形成，怎么都弄好几个月，你完全可以回家抱孩子去。但真正的杀手，盘整就是天堂。

4. 不要当死多，要充分利用自己可以把握的级别震荡去减低成本。

## 五、缠论核心概念速查

| 概念 | 说明 |
|------|------|
| **分型** | 顶分型（三K线中间最高）、底分型（三K线中间最低） |
| **笔** | 相邻顶底分型之间的连线 |
| **线段** | 至少三笔构成的走势结构 |
| **中枢** | 某级别走势类型中，被至少三个连续次级别走势类型所重叠的部分 |
| **背驰** | 价格创新高/新低，但力度指标（如MACD）未同步创新高/新低 |
| **第一类买卖点** | 背驰点 |
| **第二类买卖点** | 第一类买卖点后，次级别回试不破前低/前高 |
| **第三类买卖点** | 中枢破坏点，次级别离开中枢后不回中枢 |
| **级别** | 走势分析的时间维度（1分钟、5分钟、30分钟、日线、周线等） |
| **走势终完美** | 任何级别的任何走势类型终要完成 |
